# Hasdaq P1-5 RFC: H Coin / OE Token Decision Boundary

Date: 2026-07-03
Status: RFC / documentation only

## Decision

P1-5 does not implement exchange logic, wallet rules, redemption priority, or any claim that H coin equals OE Yuanhang coin. H coin remains a Hajimi platform unit until the school confirms any OE relationship in writing.

## Monthly Budget Facts

- Annual reimbursement path: 10,000 RMB.
- Operating plan: 800 RMB per month.
- Public token pool: 100 RMB per month.
- AI Club build AI token: 300 RMB per month.
- H coin incentive and redemption pool: 400 RMB per month.
- Monthly leaderboard incentive: 200 H coin.
- Real token redemption hard cap: 200 H coin per month.

## Product Boundary

- Hasdaq trading, product signals, and announcements must not create a real-world redemption obligation.
- Product data panels are educational review context only and must not automatically affect stock price.
- Auto announcements may describe clear server-side events such as bell listing, but should not be generated from page refreshes or product panel reads.
- Any future OE relationship needs a separate approval, implementation plan, copy review, and risk review before code changes.

## Open Questions

- Whether redemption priority should distinguish onboarding grants, monthly awards, project tips, and Hasdaq gains.
